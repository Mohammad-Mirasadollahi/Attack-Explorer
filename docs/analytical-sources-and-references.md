## 1. Multi-Source Cross-Vendor Threat Intelligence & Synthesis Standard

### 1.1 Why Single-Source Attack Analysis Is Never Enough

In real-world incident response and threat intelligence, **no single vendor or advisory captures the entire anatomy of a sophisticated cyber attack**. Different security organizations observe different layers of the same intrusion depending on their telemetry vantage point:

```
┌────────────────────────────────────────────────────────────────────────────────────┐
│ VANTAGE POINT A · VULNERABILITY & EXPLOIT MECHANICS RESEARCHERS                    │
│ (e.g., ProjectDiscovery, Assetnote, Rapid7, Praetorian, Volexity, SonarSource)     │
│ • Discovers the exact HTTP/AJP/TLS wire format, path-traversal normalization bug,  │
│   buffer/heap calculation error (`snprintf`, `mod_proxy_ajp`, `PathInfo`), or      │
│   zero-day initial access vector.                                                  │
├────────────────────────────────────────────────────────────────────────────────────┤
│ VANTAGE POINT B · ENDPOINT, MEMORY & ROOTKIT REVERSE ENGINEERS                     │
│ (e.g., Elastic Security Labs, Kaspersky GReAT, Mandiant, Unit 42, Avast, Talos)    │
│ • Dissects the post-exploitation loader chain in RAM (`UPSTYLE`, `ZIPLINE`,        │
│   `Line Dancer`, `COATHANGER`, `FudModule`, `DUSTTRAP`, `TriangleDB`), kernel      │
│   DKOM structures (`PreviousMode`, `ntdll.dll` unhooking), and C2 protocols.       │
├────────────────────────────────────────────────────────────────────────────────────┤
│ VANTAGE POINT C · SIEM, SOC & NATIONAL CYBER DEFENSE AGENCIES                      │
│ (e.g., CISA KEV / Joint Advisories, Splunk SURGe, Microsoft MSTIC, NCSC-NL/MIVD)   │
│ • Publishes enterprise-wide hunting queries (`Sysmon EventID 1..25`, `SPL`,        │
│   `Sigma`, `Zeek`, `CloudTrail`), Integrity Checker Tool (ICT) forensic steps,     │
│   and post-patch session-revocation mandates (`kill aaa session`, factory reset).  │
└────────────────────────────────────────────────────────────────────────────────────┘
```

If an analyst writes a scenario using only **Vantage Point A**, the reader learns how the initial packet bypassed authentication, but misses how the implant hid in memory or survived reboots. Conversely, relying only on **Vantage Point B** or **C** leaves the initial exploit mechanics vague.

### 1.2 Mandatory Multi-Source Search & Synthesis Workflow

Whenever authoring a new attack scenario, auditing/updating an existing scenario, or executing live threat-intelligence grounding (`/api/threat-intel`), the system and engineering workflow **must** follow these 4 steps:

1. **Search Across At Least 3 Independent Analytical Sources (`>= 3 Vantage Points`)**:
   - Query multiple independent research portals covering:
     1. **Initial Access / Exploit Root-Cause Source** (Vendor PSIRT, NVD, Assetnote, ProjectDiscovery, Rapid7, Huntress, or Volexity).
     2. **Implant / Memory / Post-Exploitation Source** (Mandiant, Unit 42, Elastic Security Labs, Kaspersky GReAT, Cisco Talos, Avast, or Microsoft Threat Intelligence).
     3. **Defensive Detection & Incident Response Source** (CISA Joint Advisories, Splunk SURGe, Microsoft Sysinternals/Learn, NCSC-NL, or SigmaHQ).
2. **Cross-Reference & Merge Complementary Technical Facts**:
   - Combine the exact URI/header/byte-level exploit mechanics from Source 1, the process/memory/loader architecture from Source 2, and the SIEM/EDR/forensic detection artifacts from Source 3 into a unified **Story-to-Spec** narrative with **Inline Purpose Parentheticals**.
3. **Document Explicit Multi-Source Synthesis (`multiSourceSynthesis`)**:
   - Every scenario in `lib/attack-sources-and-legal.ts` and `lib/threat-intel-service.ts` must include a dedicated `multiSourceSynthesis` summary that explicitly states *which* analytical detail came from *which* complementary source.
4. **Live Multi-Source Search Grounding (`/api/threat-intel`)**:
   - When syncing live intelligence via Google Search Grounding, the query prompt must explicitly instruct the search engine to cross-reference multiple independent security research teams rather than summarizing a single article, and merge live web citations with verified multi-vendor references.
